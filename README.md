# LAN Build
This is the LAN version of Eastern Sun Resurrected meant to work with D2RLan program developed by bonesy in order to be able to play with other people over TCP/IP.
There are some significant changes between the single player and LAN builds, including but not limited to:
1. Assassin mod chance to not consume charges does not exist in LAN. This stat was replaced with something else on all items.
2. LAN build is also a bit limited when it comes to the creation of new items which have aura based effects because the states.txt file is limited to 255 entries instead of the 511 on the newest d2r version.

# Eastern Sun Resurrected
Eastern Sun Resurrected is an individual effort to extend the port that tireheb and bonesy made for the classic eastern sun mod. This enhancement will be long term and will include almost everything: skill reworks, class rebalance, increased difficulty, new content, new recipes etc.

There is no end in sight for the support of this mod unless announced otherwise.

# Installation Guide
You need to download D2Launch for the best experience, which can be found here: https://www.d2rmodding.com/modtools

Once you have installed D2Launch, click on download new mod and choose Eastern Sun Resurrected from the dropdown then press Install Mod. Once the mod is installed, click on Home on the left menu to refresh D2launch, Eastern Sun Resurrected should appear as a mod choice in the home dropdown. Press play mod and enjoy.

When new updates are released, you'll be able to click on Check for Mod Updates and this will update the mod automatically.

# Disclaimer
I strongly suggest you use the periodic Auto-Backup Characters option from D2Launch (Options -> QoL Options). Saves may occasionaly get corrupted or stuff can disappear (due to some engine limitations), so it's best to have a backup option.
